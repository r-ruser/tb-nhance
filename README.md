# NHANES paired tuberculosis tests, environmental biomarkers and fatty acids

Analysis and figure source for the 2011–2012 NHANES study of QFT-only versus TST-only positivity. The 188-marker registry includes environmental and essential-element biomarkers. The targeted lipid panel has 30 individual fatty acids and four modules.

## Inputs and execution

The scripts use the original relative analysis directories. Run R from the project root except for 10_threshold_panels.R, which runs inside EHP_R2_20261118. Install the R libraries used by each script (including survey, svyVGAM, haven, ggplot2, cowplot, patchwork and svglite). The original survey fits used R 4.6.2 and survey 4.5. The figure assembly scripts use Node.js, Playwright with Chromium, and Mermaid 11.12.0. For example, run `npm install --no-save playwright` and `npx playwright install chromium` in the project root. The original PDF graphics device in some R scripts uses macOS Quartz.

1. The raw-reconstruction script in NHANES_TB_Stage3_Inference_Audit_20261116 links public NHANES components by SEQN and derives paired states, covariates and the analysis domain. Source components are available from [NCHS](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2011). The Chinese-named review and clinical directories contain the conditional models, fatty acid definitions, nutrition and path analyses.
2. The scripts in 全元素谱复核_20261118/code estimate and audit the expanded exposure and lipid screens. Earlier estimates, the candidate registry, public component imports, derived R objects and aggregate intermediate tables are expected at the paths stated in the scripts. The repository is a code distribution. A clean checkout alone does not contain those inputs.
3. EHP_R2_20261118/code/01–04 fit the survey sensitivity, joint-weight, spline and covariate models. Scripts 12 and 14 cover alternative calibration, multiplicity, nativity, sparse cells and four-state models. Script 22 audits exposure overlap. Script 15 links the sign comparisons and plots the profiles. The scripts retain earlier stage output names. When using the accompanying aggregate tables, populate Source_data, Validation and B_results at the version paths referenced by the scripts and create the corresponding output directories.
4. For the final figures, the unified-circular R script supplies the state composition and circular lipid forest. Place its Figure1_B_states.svg and Figure3_circular_forest.svg in EHP_R2_20261118/Figures. Scripts 05, 10, 15 and 17 produce spline, threshold, module, nutrition, concordance and full-spectrum panels. Run scripts 16 and 19 from the project root to assemble the final panels.
